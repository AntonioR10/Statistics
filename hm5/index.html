HMWK 5: Welford's Recurrence & Sampling Statistics

Ex. 1 – Welford’s Recurrence Formulas

1. Mathematical Derivation

Given a sequence $x_1, x_2, \dots, x_k$, let $\bar{x}_k = \frac{1}{k}\sum_{i=1}^{k} x_i$ and define the innovation $\delta_k = x_k - \bar{x}_{k-1}$.

Mean Recurrence (Knuth's Formula)

Start from $k\,\bar{x}_k = \sum_{i=1}^{k} x_i = (k-1)\,\bar{x}_{k-1} + x_k$. Dividing by $k$:

$$\bar{x}_k = \frac{(k-1)\bar{x}_{k-1} + x_k}{k} = \bar{x}_{k-1} + \frac{x_k - \bar{x}_{k-1}}{k} = \bar{x}_{k-1} + \frac{\delta_k}{k}$$

Two useful consequences: $\;\bar{x}_k - \bar{x}_{k-1} = \dfrac{\delta_k}{k}\;$ and $\;x_k - \bar{x}_k = \delta_k - \dfrac{\delta_k}{k} = \dfrac{k-1}{k}\,\delta_k$.

Sum of Squares ($M_{2,k}$) Recurrence

Define $M_{2,k} = \sum_{i=1}^{k} (x_i - \bar{x}_k)^2$ and isolate the last term:

$$M_{2,k} = (x_k - \bar{x}_k)^2 + \sum_{i=1}^{k-1} (x_i - \bar{x}_k)^2$$

For $i < k$, write $x_i - \bar{x}_k=(x_i - \bar{x}_{k-1}) - \dfrac{\delta_k}{k}$ and expand the square:

$$\sum_{i=1}^{k-1} (x_i - \bar{x}_k)^2 = \underbrace{\sum_{i=1}^{k-1}(x_i - \bar{x}_{k-1})^2}_{M_{2,k-1}} - \frac{2\delta_k}{k}\underbrace{\sum_{i=1}^{k-1}(x_i - \bar{x}_{k-1})}_{=\,0} + (k-1)\frac{\delta_k^2}{k^2} = M_{2,k-1} + \frac{(k-1)\,\delta_k^2}{k^2}$$

The last term is $(x_k - \bar{x}_k)^2 = \dfrac{(k-1)^2}{k^2}\delta_k^2$. Adding the two pieces:

$$M_{2,k} = M_{2,k-1} + \frac{(k-1)\,\delta_k^2}{k^2} + \frac{(k-1)^2\,\delta_k^2}{k^2} = M_{2,k-1} + \frac{k-1}{k}\,\delta_k^2$$

Finally, since $\frac{k-1}{k}\delta_k = x_k - \bar{x}_k$:

$$\boxed{M_{2,k} = M_{2,k-1} + (x_k - \bar{x}_{k-1})(x_k - \bar{x}_k)}$$

Sample Variance

$$s_k^2 = \frac{M_{2,k}}{k - 1}, \qquad k \ge 2$$

2. Core Logic Implementation

// Online update for a new value x at iteration k (1-indexed):
const delta = x - mean;
mean += delta / k;
M2 += delta * (x - mean);   // sample variance = M2 / (k - 1), valid for k >= 2

3. Statistical Conclusions

Unbiased Estimators E[X̄] = μ, E[S²] = σ²

For every $n$, the average sampling mean is close to $\mu$ and the average sampling variance is close to $\sigma^2$ (thanks to Bessel's correction $n-1$). Small deviations are Monte Carlo noise and shrink as $m$ grows. Even for $n=2$ there is no systematic bias.

Inferential Relevance Estimation

Since the true $\mu$ and $\sigma^2$ are typically unknown, unbiased estimators guarantee that, on average over repeated samples, sample calculations estimate the population parameters without systematic error. The measured spread of the estimators also quantifies their precision (standard errors, confidence intervals).

Impact of Sample Size ($n$) Var = σ²/n

Increasing $n$ reduces $\text{Var}(\bar{X}) = \sigma^2/n$ and also $\text{Var}(S^2)$, which decays roughly as $1/n$. Both estimators concentrate around the true values (consistency), so individual hackers' estimates become more and more similar to each other.
