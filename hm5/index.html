Ex. 1 – Welford’s Recurrence Formulas

1. Mathematical Derivation

Given a sequence $x_1, x_2, \dots, x_k$:

Mean Recurrence (Knuth's Formula)

$$\bar{x}_k = \frac{1}{k} \sum_{i=1}^{k} x_i = \bar{x}_{k-1} + \frac{x_k - \bar{x}_{k-1}}{k}$$

Sum of Squares ($M_{2,k}$) Recurrence

Defining $M_{2,k} = \sum_{i=1}^{k} (x_i - \bar{x}_k)^2$, we isolate the last term:

$$M_{2,k} = (x_k - \bar{x}_k)^2 + \sum_{i=1}^{k-1} (x_i - \bar{x}_k)^2$$

Using $(x_i - \bar{x}_k) = (x_i - \bar{x}_{k-1}) + (\bar{x}_{k-1} - \bar{x}_k)$ and expanding:

$$M_{2,k} = M_{2,k-1} + (x_k - \bar{x}_{k-1})(x_k - \bar{x}_k)$$

Sample Variance

$$s_k^2 = \frac{M_{2,k}}{k - 1}$$

2. Core Logic Implementation

// Online update loop for a new value x at iteration k (1-indexed):
const delta = x - mean;
mean += delta / k;
M2 += delta * (x - mean); // Sample Variance = M2 / (k - 1)

3. Statistical Conclusions

  • Unbiased Estimators: The average sampling mean approaches $\mu$, and the average sampling variance approaches $\sigma^2$ (due to Bessel's correction $n-1$).
  • Inferential Relevance: Since true population parameters $\mu$ and $\sigma^2$ are typically unknown, unbiased estimators guarantee that sample calculations reliably estimate population traits without systematic bias.
  • Impact of Sample Size ($n$): Increasing $n$ reduces variance according to $\text{Var}(\bar{X}) = \frac{\sigma^2}{n}$, leading to tighter convergence of trajectory means around the expected value $\mu$.
