4. Statistical Exploration

We use the points kG for k = 1…n−1, where n is the order of G.

5. Discussion

What the Data Shows

  • Periodicity: kG has period n (the order of G). For k > n, the result is the same as (k mod n)G.
  • Symmetry: (n − k)G = −kG, so the points have the same x-coordinate and opposite y-coordinates (mod 17). Therefore, x-coordinates occur in pairs.
  • Input/output correlation: with such a small field, the measurements are noisy and show no simple linear relationship.
  • Avalanche effect: the average Hamming distance calculated from the few available points is not statistically significant.

Which Properties Matter for a One-Way Function (ECDLP)?

  • Easy to compute forward, difficult to reverse: computing kG takes O(log k) operations using double-and-add, while recovering k typically requires about √n operations with generic algorithms.
  • Determinism and group structure: these are essential for digital signatures and key exchange, since (ab)G = a(bG).

Typical Properties of Cryptographic Hash Functions (Not Required for kG)

  • Strong avalanche effect (approximately 50% of output bits change): a desirable property of cryptographic hash functions, but not a requirement for kG, which preserves an algebraic structure.
  • Collision resistance and the ability to process inputs of arbitrary length.
  • Apparently uniform bit distribution: the coordinates of kG are constrained by the elliptic curve equation (y² = x³ + 7 mod 17), so they are not uniformly distributed over all possible coordinate values.
With such a small field and group order, no statistical test can demonstrate cryptographic security. The purpose of this exercise is to understand the underlying mechanism.
